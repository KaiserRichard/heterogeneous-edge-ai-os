MEASURED (real UART, MCU timestamps)

Nearest-rank receipt age quantiles, us. Condition quantiles pool accepted deliveries from valid runs; counts and state times are summed. Both strict >100 ms and >150 ms misses use accepted deliveries as denominator. Counts and receipt ages include shutdown drain; STATE_EVENT occupancy uses the RAW measurement window. Mapped receipt time uses the nearest echo affine fit (including retrospective startup mapping), at most 2 s away, with all fit RMS <=200 us. Online mapping remains in inf_rx.csv. MCU age is the supervisor evaluation estimate: send age + receipt-to-evaluation elapsed + provisional transit allowance. It includes MCU queue delay and is separate from mapped receipt AoI. Missing identities, loss reports, missing clock/state evidence, monitor gaps, live/new sticky bits, or failed process/settings checks exclude a run. Unreported sends remain separate from losses/skips/overwrites.
