# Prompts and skills

Reusable instruction sets for other AI agents (ChatGPT Work, ChatGPT projects, Codex, …).

| Folder | Use |
|---|---|
| `academic-beamer-deck/` | Build or revise a paper-structured Beamer deck + AI image-prompt batch. Start with `SKILL.md`. |

How to use with ChatGPT Work or a ChatGPT project: upload `SKILL.md` (and the `template/` files)
as project files or paste `SKILL.md` as the first message, then give the task. With Codex CLI:
copy the folder to `~/.codex/skills/academic-beamer-deck/` or point the prompt at this path.
Other handoff prompts: `docs/HANDOFF_CHATGPT.md`, `docs/LEARNING_PLAN.md`, `slides/SLIDE_PLAYBOOK.md`.
